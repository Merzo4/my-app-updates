# 12 — USER GUIDE / оперативное руководство

## Безопасный сценарий
1. Скачивать только официальный Optimizer release mwo-v* из GitHub, проверять происхождение.
2. Установить в Program Files. Проверить версию в интерфейсе.
3. Сделать первичный Smart Audit, прочитать рекомендации, не применять всё подряд.
4. Выбрать соответствующий задаче LIGHT/GENERAL/GAME SAFE профиль или отдельные элементы.
5. Изучить список «Выбранное» и класс риска. Сделать snapshot, затем Apply; дождаться Verify и сохранить log.
6. Проверить результат после перезагрузки через повторный аудит и фактическую нагрузку.
7. При проблеме использовать Undo/RestoreAll, сверив что конкретно было изменено.

## Игровая оптимизация
Сначала SAFE/PERFORMANCE. EXTREME/LAB может ухудшить совместимость сетевых/периферийных/фоновых функций и требует recovery preflight и осознанного согласия. Не обещать фиксированный FPS.

## Аудит процессов
R55.1: 15-минутный поиск поздно запущенных процессов. R56 отдельно показывает оставшийся постоянный фон, но на 2026-10-18 не опубликован. R57 планирует кнопку подготовки SAFE-действий для Edge/Chrome/Widgets; этот код ещё не прошёл локальный FULL SAFE и в текущей public версии недоступен.

## Обновления/ошибки
Использовать встроенный Update Center только после проверки реального доступного release. При падении, ошибке UAC, проблеме сети или невосстановимых изменениях — прекратить новые оптимизации, сохранить sanitized report, восстановиться через предусмотренный безопасный путь.

## Предупреждение
Функции условны для версии Windows, драйверов и установленных приложений. Некоторые строгие настройки влияют на комфорт и совместимость. Пользовательские файлы, Defender, Windows Update, Store, IPv6, pagefile не должны удаляться/отключаться ради «ускорения».
