# REPORTS — рабочие отчёты

Every meaningful work cycle has a report YYYY-MM-DD-NNN-topic.md. Owner-friendly summary and links to exact actions/evidence. Never use this as a replacement for immutable chronological ACTION LOG in EXECUTION_LEDGER/.

A report must contain:
- Date/objective/author/operator.
- Repo + branch + HEAD before/after + separate code SHA for docs-only.
- Changed paths and rationale.
- Before/after behavior (or docs-only).
- Tests: command/workflow ID, machine/OS, risk boundary, status PASS/FAIL/PENDING/NOT RUN.
- Known limitations/blockers/DO NOT REPEAT.
- EXACT NEXT EXECUTION.
- Link to immutable checkpoint.

No secrets, private machine details or unapproved publication. Reports may be corrected with explicit amendment/superseding report, never falsify prior evidence.
